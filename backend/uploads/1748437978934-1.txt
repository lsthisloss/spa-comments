1. Декоратори модулів
@Module: Використовується для визначення модуля, який є основною одиницею організації коду в NestJS. Модуль групує контролери, провайдери та інші компоненти.
typescript

Копіювати
import { Module } from '@nestjs/common';
import { CatsController } from './cats.controller';
import { CatsService } from './cats.service';

@Module({
  controllers: [CatsController],
  providers: [CatsService],
  exports: [CatsService],
})
export class CatsModule {}
controllers: Список контролерів, які обробляють запити.
providers: Список сервісів або інших провайдерів.
exports: Компоненти, які можуть використовуватися іншими модулями.
2. Декоратори контролерів
@Controller(prefix?): Позначує клас як контролер, який обробляє HTTP-запити. Параметр prefix задає префікс для всіх маршрутів у контролері.
typescript

Копіювати
import { Controller, Get } from '@nestjs/common';

@Controller('cats')
export class CatsController {
  @Get()
  findAll() {
    return ['cat1', 'cat2'];
  }
}
У цьому прикладі маршрут /cats обробляється методом findAll.
3. Декоратори маршрутів
Ці декоратори визначають HTTP-методи для обробки запитів:

@Get(path?): Обробляє GET-запити.
@Post(path?): Обробляє POST-запити.
@Put(path?), @Patch(path?), @Delete(path?): Для відповідних HTTP-методів.
@All(path?): Обробляє всі типи HTTP-запитів.
typescript

Копіювати
@Post('create')
createCat() {
  return 'Cat created';
}
Маршрут: POST /cats/create.
4. Декоратори параметрів
Використовуються для отримання даних із запиту:

@Param(key?): Витягує параметри з URL.
@Query(key?): Витягує query-параметри.
@Body(key?): Витягує дані з тіла запиту.
@Req(), @Res(): Надає доступ до об’єктів запиту та відповіді (з Express).
typescript

Копіювати
@Get(':id')
findOne(@Param('id') id: string) {
  return `Cat with ID ${id}`;
}
Маршрут: GET /cats/123 поверне Cat with ID 123.
5. Декоратори провайдерів
@Injectable: Позначує клас як провайдер (сервіс, репозиторій тощо), який може бути введений через DI.
typescript

Копіювати
import { Injectable } from '@nestjs/common';

@Injectable()
export class CatsService {
  findAll() {
    return ['cat1', 'cat2'];
  }
}
Цей сервіс може бути введений у контролер через конструктор.
@Inject(token): Використовується для явної ін'єкції залежностей, якщо потрібно вказати нестандартний токен.
typescript

Копіювати
constructor(@Inject('CUSTOM_TOKEN') private customService: any) {}
6. Декоратори middleware, pipes, guards тощо
@UsePipes(pipe): Застосовує pipe (наприклад, для валідації чи трансформації даних).
typescript

Копіювати
@Post()
@UsePipes(new ValidationPipe())
create(@Body() createCatDto: CreateCatDto) {
  return 'Cat created';
}
@UseGuards(guard): Застосовує guard для перевірки доступу.
typescript

Копіювати
@UseGuards(RolesGuard)
@Get('admin')
adminRoute() {
  return 'Admin only';
}
@UseInterceptors(interceptor): Застосовує інтерцептори для модифікації запиту/відповіді.
7. Кастомні декоратори
NestJS дозволяє створювати власні декоратори за допомогою функції SetMetadata або createParamDecorator.

Приклад кастомного декоратора для ролей:
typescript

Копіювати
import { SetMetadata } from '@nestjs/common';

export const Roles = (...roles: string[]) => SetMetadata('roles', roles);
